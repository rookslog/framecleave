# Evaluation discipline

Freeze detector configuration before evaluating held-out labels. Record selection,
annotation provenance, coverage limitations and the frozen revision locally.
Candidate-assisted, single-assessor labels are not exhaustive ground truth.
One-to-one exact-frame matching must report false positives and negatives rather
than counting review candidates as automatic detections.

Private evaluation artifacts, including source hashes and numeric measurements,
are not distributed. Public evidence uses original generated fixtures only.
