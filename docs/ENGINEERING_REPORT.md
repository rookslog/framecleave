# Engineering candidate scope

This is an engineering candidate, not certification of unattended detection or
general media/player support. Read the README for the behavior of this revision.

The implementation uses zero-based half-open decoded ordinals, integer PTS and
rational time bases. Detection candidates and human review are separate from
accepted cuts; scores are not calibrated probabilities. Exact export contracts
must not be confused with intentionally approximate review workflows.

Tests generate original media for timeline, export, audio, batch and resume
contracts. Public detector evidence is synthetic, not private-corpus performance.
Independent domain annotation, consumer playback, subjective quality, learned
detector comparison and general hardware qualification remain separate work.

Private evaluation results and original historical reports are retained locally,
not published. See detector evaluation, benchmark instructions, release guidance
and the privacy cleanup record for the disclosure boundary.
