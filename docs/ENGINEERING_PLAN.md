# Engineering workflow

Maintain a local installable CLI, a rational decoded-frame scene partition,
auditable detection evidence, atomic no-clobber outputs and conservative resume.
Source media is never modified. Use generated integration fixtures for arbitrary
cuts, B frames, VFR, audio clocks, color, rotation, corruption and short scenes.

Keep private media and all content-derived evaluation artifacts outside Git,
packages and GitHub. Publish synthetic evidence only. Detection reliability,
consumer-player compatibility and native hardware qualification are separate gates.

See the engineering report, architecture, cutting policy and public benchmark
instructions. Feature-specific amendments live in the corresponding design/plan.
